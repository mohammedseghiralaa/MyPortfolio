# Alaa's Portfolio

Personal portfolio website showing my projects, skills and contact details.

**Live site:** https://alaa-portfolio-tau.vercel.app

<img width="947" height="431" alt="Portfolio screenshot" src="https://github.com/user-attachments/assets/dd41d30b-044a-4ed5-9d7f-39eca206545e" />

## Features
- Skills managed with Sanity CMS, so I can update them without changing code
- Built with Next.js and TypeScript, styled with Tailwind CSS
- Deployed on Vercel

## Tech stack
Next.js, TypeScript, Tailwind CSS, Sanity CMS, Vercel

## Run it locally
```bash
git clone https://github.com/mohammedseghiralaa/MyPortfolio.git
cd MyPortfolio
npm install
npm run dev
```
- Website: http://localhost:3000
- Sanity Studio (content editor): http://localhost:3000/studio
